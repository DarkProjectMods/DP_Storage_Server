# DP_Storage_Server

Серверный мод DayZ: управление persistence-слоем и экономикой **без остановки
сервера**. Работает поверх [KR_GRAFTED](https://github.com/KRdayzmodding/KR_GRAFTED);
без ядра мод неактивен и ничему не мешает.

> **Исходники закрыты.** Разработка продолжается в приватном репозитории.
> По вопросам доступа — владельцы организации DarkProjectMods.

## Возможности

- **Живая экономика** — изменение параметров лута и динамических событий на
  работающем сервере: правите конфиги миссии, применяется без рестарта;
  мир приводится к новым значениям (доспавн недостающего, срезание излишка)
- **Поддержка модовых конфигов** — экономика собирается из всех подключённых
  файлов типов и событий, включая модовые
- **Вайпы** — точечная или полная очистка персонажей и слоёв мира (лут,
  транспорт, зомби, животные, тайники) живьём или при следующем старте;
  игроки не затрагиваются
- **Веб-панель** — текущее состояние экономики и сервера, журнал изменений,
  управление всеми операциями из браузера
- **Зеркало данных** — SQL-копия состояния сервера для людей и внешних
  инструментов, с безопасным асинхронным обновлением

Совместимость: DayZ 1.30+, сервер Windows. Установка и настройка — по запросу.
